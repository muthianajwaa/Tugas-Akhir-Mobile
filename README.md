*📚 BookTrack*
*Aplikasi Peminjaman dan Pendataan Buku*

BookTrack merupakan aplikasi Android sederhana yang dibuat menggunakan *MIT App Inventor* untuk membantu proses pendataan dan pencatatan peminjaman buku secara digital.

Aplikasi ini menggunakan *Firebase Realtime Database* sebagai penyimpanan data eksternal serta komponen *Barcode Scanner* untuk mendukung identifikasi buku.

 *✨ Fitur Utama*
- *Login* – Halaman masuk pengguna.
- *Dashboard* – Navigasi utama aplikasi.
- *Data Buku* – Menambahkan dan menyimpan informasi buku.
- *Barcode Scanner* – Memindai kode barcode buku.
- *Peminjaman* – Mencatat data peminjaman buku.
- *Riwayat* – Menampilkan daftar data yang tersimpan.

*🛠️ Teknologi*
- MIT App Inventor
- Firebase Realtime Database
- Barcode Scanner
- Visual Block Programming
